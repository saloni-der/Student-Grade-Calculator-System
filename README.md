# 🎓 Student Grade Calculator

The Student Grade Calculator is a simple Python-based project designed to calculate and display a student's academic performance. The program takes the student's marks in different subjects, calculates the total marks and percentage, assigns a grade, and determines whether the student has passed or failed.

The project is divided into three Python modules making the code organized and easy to understand:

- student_input.py – Stores and provides the student's name and subject marks.
- grade_calculator.py – Calculates total marks, percentage, grade, and pass/fail result.
- main.py – Connects the modules and displays the final student result in a clean format.

# Working Flow
Student Details
      ↓
Subject Marks
      ↓
Calculate Total
      ↓
Calculate Percentage
      ↓
Assign Grade
      ↓
Check Result
      ↓
Display Student Result
